# Gravador de Aulas V1 (PWA) — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA para iPhone que grava aulas de até 1h30 em partes de 1 minuto, transcreve com marcação de tempo e gera reescrita e resumo com Gemini, guardando tudo no Supabase.

**Architecture:** App React (Vite, PWA) grava com MediaRecorder reiniciado a cada 60 s, guarda cada parte no IndexedDB e sobe para o Supabase Storage. Uma Edge Function processa a aula um bloco de 10 partes por chamada (Gemini devolve trechos com tempo por parte; o servidor converte para tempo absoluto) e no fim gera reescrita e resumo. Jobs agendados retomam aulas paradas e apagam áudio com mais de 30 dias.

**Tech Stack:** React 18 + Vite + TypeScript, vite-plugin-pwa, @supabase/supabase-js, idb, Vitest + fake-indexeddb; Supabase (Auth, Postgres, Storage, Edge Functions em Deno, pg_cron); Gemini Flash via REST; Vercel.

**Spec:** [Gravador de aulas: desenho da V1](https://claude.ai/artifact/TuVeW6rTyqX3kp38wwp4bQ)

## Global Constraints

- Alvo: Safari no iPhone, instalado na tela inicial (PWA). Sem App Store.
- 1 ou no máximo 2 usuários. Cadastro aberto desligado; usuários novos só por convite (painel do Supabase).
- Custo alvo R$ 0: só níveis grátis. Nenhum serviço pago sem aprovação do Arthur.
- Partes de áudio de 60 s; blocos de 10 partes para a IA. O resultado é uma transcrição única e contínua.
- Ao bloquear a tela ou trocar de app: **pausar**, nunca encerrar. Um toque retoma a mesma aula. Nada já gravado pode se perder.
- Em 1h30 (5400 s gravados) o app **pergunta** se pode parar; não para sozinho.
- Tela acesa durante a gravação (Wake Lock).
- Filtro de voz ligado por padrão, com opção de desligar.
- Áudio apagado 30 dias após a aula; texto permanente.
- Interface em português. Aulas em português.
- Chave do Gemini só no servidor (`supabase secrets`), nunca no app.
- Modelo: Gemini Flash mais recente do nível grátis (confirmar o nome no AI Studio; constante única `GEMINI_MODEL`).

## Review Focus

1. **Ligação, Siri ou alarme no meio de uma parte** → a parte parcial é salva antes da pausa (teste na Task 3).
2. **App fechado ou recarregado no meio da aula** → partes pendentes no IndexedDB sobem ao reabrir e a aula pode ser retomada (teste na Task 4).
3. **Bloco em silêncio (intervalo, professor saiu)** → Gemini devolve vazio e a aula segue normal (teste na Task 6).
4. **Limite do Gemini (HTTP 429)** → o bloco fica pendente e é tentado de novo depois; a aula não vira "erro" permanente (teste na Task 6).
5. **Permissão do microfone negada** → mensagem clara e nenhuma aula vazia criada (teste na Task 5).

## Tipos compartilhados (referência para todas as tasks)

```ts
type LessonStatus = 'recording' | 'uploading' | 'processing' | 'ready' | 'error';
type Lesson = { id: string; user_id: string; title: string; subject: string | null;
  recorded_at: string; duration_s: number; status: LessonStatus;
  processed_blocks: number; total_blocks: number | null; audio_expires_at: string; audio_deleted: boolean };
type AudioChunk = { lesson_id: string; idx: number; start_s: number; duration_s: number; path: string };
type Segment = { start_s: number; end_s: number; text: string; speaker: string | null };
type ModelSegment = { part: number; start: number; end: number; text: string }; // part = 0..9 dentro do bloco
```

### Task 6: Processamento com Gemini

**Files:**

- Test: `supabase/functions/_shared/blocks.test.ts`, `gemini.test.ts`

**Interfaces:**
- Produces:
  - `groupIntoBlocks(chunks: AudioChunk[], size = 10): AudioChunk[][]` (ordena por idx).
  - `toAbsoluteSegments(block: AudioChunk[], segs: ModelSegment[]): Segment[]` — `start_s = block[part].start_s + start`, idem fim; descarta `part` fora do bloco e texto vazio; ordena por `start_s`.
  - `transcribeBlock(parts: { data: Uint8Array; mimeType: string }[]): Promise<ModelSegment[]>` — uma requisição `generateContent` com as partes em ordem como `inline_data`, `responseMimeType: 'application/json'` e `responseSchema` de `ModelSegment[]`. Lança `RateLimitError` em 429.
  - `rewriteAndSummarize(transcript: string): Promise<{ rewrite: string; summary: string }>` (Markdown).
  - `POST process-lesson { lessonId }` → faz **um** passo: se há bloco não processado (`processed_blocks < total_blocks`), transcreve e grava os segmentos, incrementa `processed_blocks`; se todos prontos e não há saídas, gera reescrita e resumo e marca `ready`. Responde `{ status, processed_blocks, total_blocks }`. Em `RateLimitError` responde 200 com status `processing` sem mudar nada. Outra falha 3 vezes no mesmo bloco → `error`.
- Prompt de transcrição (`prompts.ts`): português; as partes são minutos consecutivos da mesma aula; transcrever **só a fala do professor**, ignorar conversas paralelas e ruído; tempos em segundos relativos ao início de cada parte; parte em silêncio → nenhuma linha.
- Prompt de reescrita: texto organizado por tópicos com títulos, sem inventar conteúdo; resumo em até 15 tópicos.
